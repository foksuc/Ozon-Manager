<a id="welcome"></a>
## 👋 Добро пожаловать

**Ozon Manager** — локальное приложение для продавца Ozon. Оно объединяет работу с акциями, автодобавлением, остатками и историей операций в одном интерфейсе.

Приложение запускается на вашем компьютере и открывается в браузере. Оно рассчитано на одного пользователя и работает с **реальным кабинетом продавца Ozon**.

> [!IMPORTANT]
> Ozon Seller API не является sandbox. Перед изменяющими операциями приложение использует Preview, Fresh Check, Snapshot, подтверждение и проверку результата. Реальные API-ключи нельзя публиковать или добавлять в GitHub.

<a id="install"></a>
## 🛠 Установка для новичка

Ниже самый простой вариант для Windows 10/11. Для обычной установки не нужно вручную создавать `.venv` или вводить команды запуска Streamlit.

### 1. Установите Python

Установите **Python 3.11 или новее** с официального сайта:

```text
https://www.python.org/downloads/
```

Во время установки включите **Add Python to PATH**, если установщик показывает такой пункт.

После установки откройте PowerShell и проверьте:

```powershell
python --version
```

Если команда `python` не найдена, попробуйте:

```powershell
py -3 --version
```

### 2. Скачайте проект

Самый простой способ через GitHub:

1. Нажмите **Code**.
2. Нажмите **Download ZIP**.
3. Распакуйте архив, например в:

```text
E:\Project\Ozon-Manager
```

Не запускайте приложение прямо из ZIP-архива.

Если вы пользуетесь Git:

```powershell
cd E:\Project
git clone https://github.com/foksuc/Ozon-Manager.git
cd Ozon-Manager
```

### 3. Запустите установщик Ozon Manager

В папке проекта дважды нажмите:

```text
INSTALL_OZON_MANAGER.vbs
```

Он автоматически:

- создаст ярлык **Ozon Manager** на рабочем столе;
- создаст локальное окружение `.venv`;
- установит зависимости из `requirements.txt`;
- подготовит папки приложения;
- запустит Streamlit;
- откроет Ozon Manager в браузере.

Первый запуск может занять несколько минут.

### 4. Последующие запуски

После установки запускайте Ozon Manager ярлыком на рабочем столе или файлом:

```text
START_OZON_MANAGER.vbs
```

Для остановки используйте:

```text
STOP_OZON_MANAGER.bat
```

Обычно приложение открывается по адресу:

```text
http://127.0.0.1:8501/
```

### Если автоматический запуск не сработал

Откройте PowerShell в папке проекта и выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app\ui\streamlit_app.py
```

Если PowerShell запрещает активацию `.venv`:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

После этого повторите:

```powershell
.\.venv\Scripts\Activate.ps1
```

<a id="first-run"></a>
## 🔑 Первый запуск

При первом запуске откроется окно **«Аккаунт»**.

Вам понадобятся:

- **Client ID** продавца;
- **API Key** Ozon Seller API.

Введите данные и нажмите:

```text
Проверить подключение к Ozon
```

После успешной проверки нажмите **Сохранить**.

Введённые через интерфейс credentials хранятся только в текущей Streamlit-сессии и не записываются в историю операций или SQLite проекта.

Никогда не публикуйте API Key в README, GitHub, issue, screenshots, тестах или исходном коде.

<a id="features"></a>
## ✅ Что умеет Ozon Manager

### 🎯 Акции Ozon

Основной экран содержит три рабочие кнопки:

- **Кандидаты — N**;
- **Участники — N**;
- **Автодобавление Ozon**.

Каждая открывает отдельное большое рабочее окно.

### Кандидаты

Можно:

- загружать кандидатов акции;
- видеть SKU, название товара и цены;
- работать с положительными и отрицательными процентами скидки;
- сортировать и фильтровать таблицу;
- выбирать отдельные товары, диапазон или все строки;
- добавлять выбранные товары в акцию через безопасный workflow;
- автоматически подготовить товары по условию **«скидка меньше X%»**.

### Участники

Можно:

- просматривать текущих участников;
- изменять `action_price`;
- применять индивидуальный или единый процент к выбранным товарам;
- удалять выбранные товары из акции;
- автоматически подготовить удаление по условию **«скидка больше X%»**;
- проверять фактический результат после mutation.

**Базовая цена товара Ozon этим workflow не изменяется.**

### Автодобавление Ozon

Отдельное окно Auto-Add:

- показывает все акции, для которых Ozon вернул `auto_add_dates`;
- располагает акции по две кнопки в строке;
- позволяет открыть нужную акцию и дату автодобавления;
- использует ту же интерактивную таблицу;
- позволяет удалять товары из Auto-Add;
- использует существующий Preview / Fresh Check / Snapshot / Confirmation workflow;
- поддерживает историю и предусмотренный проектом rollback Auto-Add.

### 📦 Остатки

Раздел **«Остатки»** позволяет:

- загружать остатки товаров;
- искать и фильтровать товары;
- работать со складами FBS/rFBS в пределах реализованного API-контракта;
- выбирать товары в общей таблице;
- подготавливать массовое изменение свободного остатка;
- подтверждать изменение перед отправкой;
- хранить историю и snapshots для предусмотренного rollback.

### 📜 История и Rollback

Раздел **«История»** содержит операции по акциям и остаткам.

Для операций, где предусмотрено восстановление, приложение сохраняет Snapshot. Rollback выполняется как отдельная mutation и снова проходит проверки безопасности.

### 🔎 Интерактивные таблицы

Таблицы поддерживают:

- сортировку;
- числовую сортировку;
- фильтр по правому клику на заголовок;
- **Содержит / Равно / Больше или равно / Меньше или равно**;
- проценты, включая отрицательные значения;
- checkbox-выбор строк;
- Shift-выделение диапазона;
- выбор всех строк;
- копирование текста;
- горизонтальную и вертикальную прокрутку;
- светлую и тёмную тему.

### 🛡 Безопасность mutation

Критичные операции проходят последовательность:

```text
Выбор товаров
      ↓
Preview
      ↓
Fresh Check
      ↓
Snapshot
      ↓
Подтверждение
      ↓
Mutation
      ↓
Read-after-write
      ↓
Проверка результата
      ↓
History
```

Приложение не должно повторять mutation вслепую после неопределённого результата и отдельно обрабатывает partial failures.

## 🔮 Что приложение может получить в будущем

Ниже — **идеи развития, а не уже реализованные функции**.

В будущем Ozon Manager можно расширить:

- выбором разных акций для экранов кандидатов и участников;
- дополнительными массовыми операциями;
- более подробными карточками товаров;
- сохранёнными фильтрами и представлениями таблиц;
- экспортом истории и reconciliation-отчётов;
- расширенной аналитикой по товарам и остаткам;
- более подробной диагностикой partial/unknown результатов;
- дополнительными возможностями Ozon Seller API после проверки актуального контракта;
- интеграциями с Ozon Performance API;
- более удобной работой с несколькими аккаунтами продавца;
- дополнительными dashboard-экранами и визуализацией.

Любая новая mutation-функция должна добавляться только после проверки актуального API-контракта, тестирования и сохранения защитного workflow проекта.
