# Запуск Ozon Manager в один клик

## Быстрый запуск

Для первого запуска дважды щёлкните:

**`INSTALL_OZON_MANAGER.vbs`**

Скрипт:

1. создаст на рабочем столе ярлык **Ozon Manager**;
2. назначит ему фирменную иконку;
3. запустит `START_OZON_MANAGER.bat`;
4. при первом запуске создаст `.venv` и установит зависимости приложения из `requirements.txt`;
5. запустит приложение.

После первой установки приложение можно запускать двойным щелчком по ярлыку.

## Прямой запуск

Также можно дважды щёлкнуть:

**`START_OZON_MANAGER.vbs`**

Он:

1. проверит наличие Python 3;
2. создаст локальное окружение `.venv`;
3. установит зависимости из единого `requirements.txt` при первом запуске;
4. создаст `data/` и `logs/`;
5. запустит Streamlit;
6. дождётся фактической готовности Streamlit;
7. автоматически откроет браузер на `http://127.0.0.1:8501/`.

## Иконка приложения

Оригинальный загруженный пользователем значок добавлен в:

- `assets/ozon_manager.png` — используется как иконка Streamlit;
- `assets/ozon_manager.ico` — используется для Windows-ярлыка.

Исходный знак сохранён, без перерисовки.

## Остановка

Дважды щёлкните:

**`STOP_OZON_MANAGER.bat`**

## Важно

- Python 3 должен быть установлен в Windows.
- Client ID и API Key не записываются в launcher.
- `.env` находится в `.gitignore`.
- Launcher не выполняет Ozon mutation сам по себе; он только запускает приложение.
